# smasi-download

This repository hosts public downloads and screenshots for **smasi** - your
personal wiki (https://www.smasi.software).

- **Releases**: pre-built Linux binaries (`.tar.gz` source archives and
  `.flatpak` bundles), published automatically by our CI pipeline.
- **`/screenshots`**: images referenced by the app's Flathub metadata.

smasi's source code is proprietary and not hosted here - this repo exists
only to provide stable, versioned download URLs for packaging purposes
(e.g. the [Flathub](https://flathub.org) submission for smasi).
